# ResistorBuilder

#### This is an application that calculates values of resistor based on coloring of resistor.

Sometimes we don't know the values of the resistor we have. The solution to fix that is to have an application that tells you resistor specification based on coloring and give you preview of your resistor for confirmation that it is the same resistor.
